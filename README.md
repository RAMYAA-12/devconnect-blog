# DevConnect Blog

A simple full stack blog application built using ReactJS and NodeJS.

## Features

- Create blog posts
- View blog posts
- Delete blog posts
- REST API integration
- Responsive user interface

## Technologies Used

- ReactJS
- NodeJS
- ExpressJS
- HTML
- CSS
